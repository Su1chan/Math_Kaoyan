# 向量组
向量的数乘和相加类似于矩阵
向量组的 n 是维度，也就是 x 的个数、列向量数
向量组的秩是极大线性无关组中所含向量个数，可以变换成行最简式观察主元个数，主元所在列就是极大线性无关组，赋值某一相关组的系数为 1，齐次线性方程可以求得表示关系

注意求解线性相关性、线性表示和基础解系、通解时，虽然都是使用线性方程组增广矩阵转行最简，<font color="#c00000">系数都是为任意常数</font>，但线性相关性给出 $A=(2,3,5,a)^T$ <font color="#c00000">需要写成列向量</font>，**方程组直接抄**

## 基础解系
基础解系不带系数，<font color="#c00000">要求线性无关，要求是齐次方程组的解，要求数量最大（n-r）</font>
A 不为方阵时，A 和 A 的转置基础解系很大概率不相同：个数和值
解是对基础解系的求和，系数为任意常数

## 已知基础解系求方程组
根据基础解系维度确定方程组维度，再根据解系个数确定方程组的秩
设方程组的一组参数 $\alpha$ 与解相乘，得到一组方程，求解即得原方程组，把 k 换成 x
