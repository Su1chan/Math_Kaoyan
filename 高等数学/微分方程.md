# 换元可分离
**齐次方程和某些方程通过换元之后都可以转换成可分离型**
1. 先考虑可分离型 dy/dx
2. 再考虑可分离型 dx/dy
3. 齐次方程考虑能否转化为关于 y/x 的函数，之后可转成可分离型
4. 线性方程使用常数变易法
