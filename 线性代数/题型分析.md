# Ax=b
![[题型分析-1790258413579.webp]]
A 的行数就是方程组包含的方程数，A 的列数就是求解的 x 维度，行数越多列数越少越好解
行数列数相同时，转化为 E 的变形
行数小于列数时，3 x 6,转换成左 E 右 0，解一定不唯一，判断无解还是无穷解
行数大于项数时，6 x 3,转换成上 E 下 0


# AP=PB 
考虑 P 是否可逆、A 与 B 是否为方阵，都满足时 AB 相似
往往 A 和 B 都是 1 行 n 列、抽象行列式，这时候构造 P 为 n 行 n 列
